# Security Policy

Thank you for your interest in reporting security issues related to this project.

## 🔐 Project Status

This repository (`Nomaryth/AgnesBot`) is a **public documentation and status repo only**.  
The **source code of Agnes Tachyon** is private and proprietary.

If you discover a security vulnerability or issue related to Agnes:
⚠️ Do **NOT** open a public issue with sensitive information.

## 🐞 How to Report a Vulnerability

Please use **private, secure communication**:

- Send an email to: `security@nomaryth.uk`  
  *(or substitute with your preferred contact)*
- Alternatively, use GitHub’s **private security advisories** (if enabled)
  and select the “Security” tab to report confidentially.

### Information to include (optional, if safe to share):

- Which version/service is affected
- Description of the vulnerability
- Steps to reproduce
- Impact assessment

> **Do not include proof-of-concept code in public places.**  
> Use private channels when sharing exploit details.

## 📢 Disclosure Policy

We follow responsible disclosure:
- We will verify and triage confirmed issues
- If appropriate, we will coordinate a fix
- We may publicly acknowledge the reporter *with consent*

---

If you need immediate assistance for critical vulnerabilities, you can reach out via the support Discord/email listed in the README.

Thanks for helping keep this project secure!
